# KLENEX photography library

This folder is the replacement-ready home for KLENEX photography. The current implementation uses centrally managed Unsplash editorial placeholders in `src/config/klenexImages.js` so the site works immediately. Replace the URLs in that file with optimized local WebP or AVIF files placed in these folders:

- `hero/` - above-the-fold home-care imagery
- `services/` - real service activity
- `workers/` - people and customer moments
- `home/` - Indian home environments
- `sections/` - editorial transition and campaign images

Use descriptive filenames matching the keys in the configuration file.
